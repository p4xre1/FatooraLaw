# Public landing font

Inter variable, Latin and Latin Extended subsets, distributed via
`@fontsource-variable/inter` version 5.3.0 (https://fontsource.org/fonts/inter).
Original project: https://github.com/rsms/inter
License: SIL Open Font License 1.1; see OFL.txt in this directory.

Registered as `Fatorati Landing Sans` and used only inside `.landing-atlas`.
It is an open-source substitute inspired by modern enterprise typography,
not Atlassian's proprietary Charlie Sans. Dashboard font settings are unchanged.
